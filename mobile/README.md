# تطبيق "حضوري" — متابعة الحضور للموظفين (Flutter)

تطبيق هاتف يتيح للموظف متابعة حضوره وانصرافه على **شبكة الوزارة الداخلية فقط**:
- الدخول: **رقم الموظف في جهاز البصمة** + رقم سري يُصرف من الداشبورد (شاشة الموظفين ← زر 🔑).
- **جهاز واحد لكل موظف**: أول جهاز يدخل بنجاح يُربط بالحساب، وأي جهاز آخر يُرفض حتى
  يضغط المدير "إعادة تعيين الجهاز" (زر 📱) في الداشبورد.
- التبويبات: **اليوم** (أول دخول/آخر خروج/تأخر) · **شهري** (ملخص ونِسب) · **سجلاتي** · **حسابي**.

## المتطلبات (مرة واحدة على الماك)
1. تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install/macos) (قناة stable).
2. تثبيت Android Studio (لتوفير Android SDK) وقبول التراخيص:
   ```bash
   flutter doctor --android-licenses
   flutter doctor   # تأكد أن Android toolchain عليه ✓
   ```

## الإعداد الأول للمشروع
مجلدا المنصات (android/ios) لا يُحفظان في المستودع — وَلِّدهما مرة واحدة:
```bash
cd mobile
flutter create . --project-name attendance_portal --org sa.gov.ministry
flutter pub get
```

ثم عدّل ملف `android/app/src/main/AndroidManifest.xml`:
1. **السماح بـ HTTP الداخلي** — أضف داخل وسم `<application ...>`:
   ```xml
   android:usesCleartextTraffic="true"
   ```
2. **اسم التطبيق بالعربية** — غيّر `android:label` إلى:
   ```xml
   android:label="حضوري"
   ```

## التجربة أثناء التطوير
وصّل هاتف أندرويد (بتفعيل خيارات المطور) أو شغّل محاكيًا، ثم:
```bash
flutter run
```
في شاشة الإعداد الأولى أدخل عنوان الخادم، مثل: `http://192.168.1.10:5005`

## بناء نسخة التوزيع (APK)
```bash
flutter build apk --release
```
الملف الناتج: `build/app/outputs/flutter-apk/app-release.apk`

**التوزيع**: أرسل ملف الـ APK للموظفين (مشاركة ملفات داخلية/USB). عند التثبيت يحتاج
الموظف السماح بـ"تثبيت من مصادر غير معروفة" — طبيعي للتطبيقات الداخلية خارج المتجر.

## خطوات تفعيل موظف
1. من الداشبورد ← الموظفون ← زر 🔑 بجانب الموظف ← يظهر **الرقم السري مرة واحدة** — سلّمه له.
2. الموظف يثبّت التطبيق، يُدخل عنوان الخادم، ثم رقمه في البصمة + الرقم السري.
3. جهازه يُربط تلقائيًا بأول دخول ناجح (يظهر طرازه للمدير في عمود "التطبيق").
4. عند تغيير هاتفه: الداشبورد ← زر 📱 "إعادة تعيين الجهاز" ← يدخل من الجهاز الجديد فيُربط.

## ملاحظات
- الأمان: قفل 15 دقيقة بعد 5 محاولات دخول خاطئة، وواجهة `/api/portal` ترفض أي عنوان
  من خارج الشبكة الخاصة (إعداد `Portal:PrivateNetworkOnly` في الخادم).
- بيانات التطبيق بحداثة آخر **مزامنة** مع جهاز البصمة.
- iOS ممكن تقنيًا (نفس الكود) لكنه يتطلب حساب Apple Developer للتوزيع — خارج النطاق حاليًا.
