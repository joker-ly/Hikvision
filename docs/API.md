# توثيق واجهة البرمجة (API) — تقارير الحضور والمرتبات

واجهة برمجية للقراءة فقط (GET) تُرجِع تقرير الحضور والمرتبات بصيغة **JSON**، لربط
المنظومة المالية أو أي نظام خارجي بالبرنامج.

> العنوان الأساسي (مثال): `http://[عنوان-الخادم]:5005`
> فتكون نقطة النهاية: `http://localhost:5005/api/payroll`

---

## المصادقة (اختيارية)
- إن تُرك الإعداد `Api:Key` فارغًا في `appsettings.json` فالواجهة **مفتوحة** بلا مصادقة.
- إن ضُبط مفتاح، يجب إرسال الترويسة في كل طلب:
  ```
  X-Api-Key: المفتاح-الذي-ضبطته
  ```
  وإلا تُرجَع `401 Unauthorized`.

---

## المعاملات (Query Parameters) — مشتركة بين كل النقاط
| المعامل | النوع | الوصف |
|---------|------|-------|
| `month` | رقم 1–12 | الشهر. يُحسب تلقائيًا من أول الشهر إلى آخره. |
| `year` | رقم | السنة. اختياري — إن لم يُرسل تُستخدم **السنة الحالية**. |
| `from` | `yyyy-MM-dd` | بداية الفترة (بديل عن `month`). |
| `to` | `yyyy-MM-dd` | نهاية الفترة (يُرسل مع `from`). |
| `groupId` | رقم | تصفية حسب المجموعة/القروب. اختياري — إن لم يُرسل تشمل **كل المجموعات**. |

**قواعد الفترة:**
- أرسل **إمّا** `month` (مع `year` اختياريًا) **أو** `from` و`to` معًا.
- `month` له الأولوية إن أُرسل مع `from/to`.
- عند الخطأ تُرجَع `400 Bad Request` برسالة توضّح الصيغة الصحيحة.

> **أين أجد رقم القروب (`groupId`)؟** من صفحة المجموعات داخل البرنامج
> (`/Groups`) — رقم المجموعة يظهر في رابط التعديل: `/Groups/Edit/3` ⟸ هنا `groupId=3`.
> وكل صف في الاستجابة يتضمّن `groupName` لتمييز المجموعة.

---

## 1) التقرير الكامل — `GET /api/payroll`

تقرير تفصيلي بكل حقول الحضور والمرتبات.

### أمثلة
```bash
# تقرير شهر بعينه لكل المجموعات (السنة الحالية)
GET /api/payroll?month=3

# تقرير بالشهر والسنة والقروب  ← (الطلب المعتاد)
GET /api/payroll?month=3&year=2026&groupId=2

# تقرير بفترة مخصّصة
GET /api/payroll?from=2026-06-01&to=2026-06-30&groupId=2
```
```bash
# مع مفتاح API
curl -H "X-Api-Key: مفتاحك" \
  "http://localhost:5005/api/payroll?month=3&year=2026&groupId=2"
```

### مثال الاستجابة
```json
{
  "from": "2026-03-01",
  "to": "2026-03-31",
  "groupId": 2,
  "count": 2,
  "rows": [
    {
      "employeeId": 12,
      "fullName": "أحمد محمد",
      "financialNo": "1023",
      "groupName": "الموظفون",
      "daysPresent": 22,
      "daysAbsent": 1,
      "daysLeave": 0,
      "workMissionDays": 0,
      "earlyExitPermissionCount": 1,
      "holidayDays": 8,
      "lateCount": 3,
      "totalLateMinutes": 45,
      "totalWorkedHours": 176.5,
      "baseSalary": 5000.00,
      "estimatedPay": 4818.18
    }
  ]
}
```

### حقول كل صف (`rows`)
| الحقل | المعنى |
|------|--------|
| `employeeId` | معرّف الموظف في النظام |
| `fullName` | اسم الموظف |
| `financialNo` | الرقم المالي (رقم المنظومة المالية) |
| `groupName` | اسم المجموعة/القروب |
| `daysPresent` | أيام الحضور (تشمل الإجازات والعطل والمهام المحتسبة) |
| `daysAbsent` | أيام الغياب |
| `daysLeave` | أيام الإجازة |
| `workMissionDays` | أيام المأموريات |
| `earlyExitPermissionCount` | عدد أذونات الخروج المبكر |
| `holidayDays` | أيام العطل الرسمية ضمن الفترة |
| `lateCount` | عدد مرات التأخّر |
| `totalLateMinutes` | إجمالي دقائق التأخّر |
| `totalWorkedHours` | إجمالي ساعات العمل الفعلية |
| `baseSalary` | الراتب الأساسي |
| `estimatedPay` | الراتب المقدّر بعد الخصومات |

## 2) الواجهة المبسّطة للمنظومة المالية — `GET /api/payroll/financial`

تُرجِع فقط: الاسم + الرقم المالي + إجمالي أيام الحضور (الأنسب للتصدير المالي السريع).

### أمثلة
```bash
GET /api/payroll/financial?month=3&year=2026&groupId=2
```

### مثال الاستجابة
```json
{
  "from": "2026-03-01",
  "to": "2026-03-31",
  "count": 2,
  "employees": [
    { "name": "أحمد محمد", "financialNo": "1023", "attendanceDays": 30 },
    { "name": "سارة علي",  "financialNo": "1044", "attendanceDays": 28 }
  ]
}
```
> `attendanceDays` تشمل الإجازات والعطل والمهام (كل ما يُحتسب حضورًا مدفوعًا).

---

## رموز الاستجابة (HTTP)
| الرمز | المعنى |
|------|--------|
| `200 OK` | نجاح، والبيانات في جسم JSON. |
| `400 Bad Request` | معامل فترة غير صالح (الرسالة في `error`). |
| `401 Unauthorized` | مفتاح API مفقود أو غير صحيح (عند تفعيل `Api:Key`). |

## ملاحظات
- كل التواريخ بصيغة `yyyy-MM-dd` وبالمنطقة الزمنية المُعدّة في `Localization`.
- الواجهة للقراءة فقط (GET) ولا تعدّل أي بيانات.
- لتأمين الواجهة عبر الشبكة، اضبط `Api:Key` في `appsettings.json` وأرسله بترويسة `X-Api-Key`.
